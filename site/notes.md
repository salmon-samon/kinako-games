## 2026-11-18 サイト本体を全力改善した（v1.0.0）

リポジトリの中からランダムで選んだ対象を全力で改善する、という回でサイト本体が当たった。

- 共通部分（タブバー／フッター／バージョン）は `site.config.mjs` が正で、`node build-site.mjs` で全ページに配る
- 色は style.css の CSS変数に集約。ページにインラインスタイルは置かない
- グラスはキーボードでも落とせる。チェックは `node site.test.mjs`
- フレームワークは「必要になった部分にだけ拡張として入れる」方針。今回は生成で足りたので入れていない

## 変換できる記法（2026-11-18に仕上げた）

md.js は雑な実装をやめて、だいたいの記法に対応させた。テストは `md.test.mjs`。

| 記法 | 書き方 |
|---|---|
| 太字・斜体 | `**太**` `*斜*` |
| 表 | この表そのもの |
| 引用 | `>` で始める |

> 引用はこんな感じに表示される。中身も変換される。

- [x] 表に対応する
- [x] 引用に対応する
- [ ] もっと凝った記法（脚注とか）はその都度
