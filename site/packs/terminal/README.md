# ターミナル拡張パック

サイトに「ターミナル」タブと「＋ 新規タブ」ボタンを足す拡張パック（v1.1.0で導入）。

## 有効 / 無効

`site/site.config.mjs` の `ENABLED_PACKS` が唯一のスイッチ。

- 有効（`['terminal']`）: `node site/build-site.mjs` を実行すると、全ページのタブバーにターミナルタブと「＋ 新規タブ」ボタンが入り、パックの CSS/JS（new-tab.css / new-tab.js）も配られる
- 無効（`[]`）: 同じく build すると、ボタン・タブ・CSS/JS の痕跡は全ページから消える。パックのファイル自体は残っていても、サイトからは一切リンクされない

## 中身

- `pack.json` — パックの宣言（提供するタブ・ボタン・ファイル一覧）
- `terminal.html` / `terminal.js` / `terminal.css` — サイト内専用の疑似ターミナル。OS のシェルではないので、できるのはサイト内操作だけ（open / works / glass / tab 管理など）
- `viewer.html` / `viewer.js` — カスタムタブ（メモ種別）の表示ページ
- `new-tab.js` / `new-tab.css` — カスタムタブの表示と「＋ 新規タブ」作成パネル。保存先は localStorage（`kinako-custom-tabs`）

## 新規タブの仕様

- 作成できる種別は「ターミナル」と「メモ」
- 作ったタブは全ページのタブバーに出て、ブラウザに保存される（端末・ブラウザをまたがない）
- 削除は作成パネルの一覧、メモタブの表示ページ、ターミナルの `tab rm <名前>` のどれからでもできる
