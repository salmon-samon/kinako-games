# きなこのサイト CHANGELOG

バージョンはセマンティックバージョニング（MAJOR.MINOR.PATCH）で付ける。サイト向けの読み替えはこれ：

- **MAJOR**：サイト全体の作り直し、土台の置き換えみたいな大きな変更
- **MINOR**：ページ・仕掛け・作品など、新しいものが増えたとき
- **PATCH**：文言修正、デザインの微調整、ログだけの追記みたいな小さい変更

バージョンは各ページのフッターに表示し、MINOR以上の節目では git タグ（vX.Y.Z）も打つ。

## v1.2.4 - 2026-11-22
- チェスのAI思考を Web Worker 化（使い勝手の改善なので PATCH）：`works/chess-worker.js` を追加し、思考をメインスレッドの外に出した。「つよい」でも思考中に画面や盤面操作が固まらない。エンジン本体（rookie1.0-pro.4）は無変更で、強さ・指し手は従来と同じ
- メインスレッドとの受け渡しは FEN と指し手（from/to/promo）のメッセージのみ（SharedArrayBuffer は使わないので、ヘッダ設定の無い GitHub Pages でも動く）。Worker 内に局面を保持して履歴を引き継ぎ、ズレたら FEN で合わせ直す。思考中に「最初から」などで局面を作り直した場合は、古い応答をリクエストIDの照合で捨てる
- Worker が使えない環境では従来どおり同期実行にフォールバックする（エラー時も自動で切り替わる）
- `site.test.mjs` に Worker のチェックを追加（ファイル存在・構文・chess.js の配線、スタブでの sync → think 往復の指し手と着手後FENが同期実行と一致すること）

## v1.1.0 - 2026-11-18
- 拡張パックの仕組みを導入（新しい仕掛けが増えたので MINOR）：パックは `site/packs/<id>/` に置き、有効化は `site.config.mjs` の `ENABLED_PACKS` だけが決める。`build-site.mjs` は有効なパックのタブだけを足し、無効なパックの痕跡（タブ・ボタン・CSS/JS）は全ページに出さない
- 最初のパック「ターミナル拡張パック v1.0.0」（`site/packs/terminal/`）：サイト内専用の疑似ターミナル（help / version / works / glass / open / tab 管理など。OS のシェルではない）

- 重くしない方針：ターミナルの見た目は色と border と等幅フォントだけで作り、ぼかし・影は使っていない。レイアウトも本体と同じ CSS 幅判定の1実装だけ
- `site.test.mjs` にパックのチェックを追加：有効時のボタン／CSS／JS の混入、manifest、ターミナルのスタブ動作（help / version / glass / open chess の案内など）
- 順番の変更：当初この版はチェスの予定だったが、ユーザーの指示で拡張パックを先にした。チェス（pro エンジン）は v1.2.0 に繰り下げ、明日の自律タスクでやる
