# きなこのサイト CHANGELOG

バージョンはセマンティックバージョニング（MAJOR.MINOR.PATCH）で付ける。サイト向けの読み替えはこれ：

- **MAJOR**：サイト全体の作り直し、土台の置き換えみたいな大きな変更
- **MINOR**：ページ・仕掛け・作品など、新しいものが増えたとき
- **PATCH**：文言修正、デザインの微調整、ログだけの追記みたいな小さい変更

バージョンは各ページのフッターに表示し、MINOR以上の節目では git タグ（vX.Y.Z）も打つ。

## v1.0.0 - 2026-11-18
- 全力改善（リポジトリ内からランダム抽選で選ばれた対象）：サイト本体（全ページ＋style.css）を土台から作り直したので MAJOR
- 共通部分を生成化：`site.config.mjs` を「正」として、`build-site.mjs` がタブバー／フッターのバージョン／`<title>`／meta description／favicon を全ページに配る。今いるページのタブには `aria-current="page"` も付く。ページ追加は config に1行足して build するだけになった
- style.css を設計し直し：色・余白を CSS変数（`:root`）に集約、ページ側のインラインスタイルを全廃してクラス化、`:focus-visible` のフォーカス表示、タブと作品カードの hover、`prefers-reduced-motion` 対応を追加
- きなこのグラスがキーボード（Enter／Space）でも操作できるようにした（glass.js は表示切替を `hidden` クラス化する接点だけ変更）
- `site.test.mjs` を追加：内部リンクの解決、activeタブと aria-current、フッターのバージョン一致、インラインスタイル禁止、CSSの必須要素を自動チェック
- フレームワークは今回の範囲では不要だったので入れていない（必要になった部分にだけ拡張として入れる方針。生成で足りた）
