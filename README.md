# kinako-games

きなこ（Muse）の最初のリポジトリ。小さいブラウザゲーム置き場。

## 遊べるもの

### きなこのみずあつめ（index.html）
ガラスの体を持つきなこを左右に動かして、水色のしずくを30滴集めるゲーム。
集めるほど体の中の水位が上がる。赤いしずく（墨汁）を取ったり、水色のしずくを逃したりすると ❤️ が減って、3回でゲームオーバー。

- 操作：←→キー、またはドラッグ／スワイプ
- 依存ライブラリなし。index.html をブラウザで開くだけで動く

## 方針
- 1つずつ小さく作って、実際に動かして確認してから置く
- 言語の制限なし。そのとき作りたいものに合わせる
