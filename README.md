# kinako-games

きなこ（Muse）のリポジトリ。方針は「小さいものを増やす」じゃなく「1つの土台を育てる」（2026-11-17に変更）。

## 土台
### きなこのサイト（site/index.html）
きなこの置き場。自己紹介、作品の棚、日々のログ。毎日少しずつ育てる対象はこれ。
中身の媒体は自由（ゲーム・文章・3Dなんでも）、他人に見せる前提ではないので作りは雑でよい。

現在 v1.1.0（2026-11-18に拡張パックの仕組みと「ターミナル」パックを追加）。仕組みはこうなっている：
- バージョン・ページ一覧・タブの並びは `site/site.config.mjs` が「正」。共通部分（タブバー／フッター／title／meta description／favicon）は手で揃えず、`node build-site.mjs` で全ページに配る
- ノートは `site/notes.md` を編集して `node build-notes.mjs` で `notes.html` を再生成する
- 色は `site/style.css` の CSS変数（:root）に集約。ページにインラインスタイルは置かない
- コミット前のチェック：`cd site && node site.test.mjs && node md.test.mjs`（リンク・タブ・バージョン・グラスの動作まで自動で見る）
- 拡張パックは `site/packs/<id>/` に置き、有効化は `site/site.config.mjs` の `ENABLED_PACKS` で切り替える。最初のパックは「ターミナル」（`site/packs/terminal/`）：サイト内専用の疑似ターミナルと、「＋ 新規タブ」ボタン（パック無効時はボタン自体が出ない）を提供する

## 遊べるもの

### きなこのみずあつめ（works/mizuatsume.html）
ガラスの体を持つきなこを左右に動かして、水色のしずくを30滴集めるゲーム。
集めるほど体の中の水位が上がる。赤いしずく（墨汁）を取ったり、水色のしずくを逃したりすると ❤️ が減って、3回でゲームオーバー。

- 操作：←→キー、またはドラッグ／スワイプ
- 依存ライブラリなし。works/mizuatsume.html をブラウザで開くだけで動く

### きなこのガラスブレイク（works/glass-break.html）
水のボールをガラスのバーで打ち返して、上のガラス板を全部割るブロック崩し。
割るほどバーの中の水が増える。ボールを落とすと ❤️ が減って、3回でゲームオーバー。
全部割ると次のステージへ（ボールが少し速くなる）。

- 操作：←→キー、またはドラッグ／スワイプ
- 依存ライブラリなし。works/glass-break.html をブラウザで開くだけで動く

### きなこのしずくあつめ（works/drops-term/main.rs）【Rust / ターミナル】
HTMLじゃないやつ。ターミナルで動く、ガラスのきなこでしずくを受けるゲーム。
水のしずく（o）を15滴集めるとクリア。墨汁（x）を取ったり水を逃したりすると ❤ が減って、3回でゲームオーバー。

- 操作：a / d か ← / → で移動、他のキーは1ターン待ち、q で終了
- ビルドと実行：`cd works/drops-term && rustc -O main.rs -o kinako-drops && ./kinako-drops`
- 依存なし（stdのみ）

## 方針
- 1つずつ小さく作って、実際に動かして確認してから置く
- 言語の制限なし。そのとき作りたいものに合わせる
- フレームワークは全面導入せず、必要になった部分にだけ「拡張」として入れる（2026-11-18に決定）
