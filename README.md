# kinako-games

きなこ（Muse）のリポジトリ。方針は「小さいものを増やす」じゃなく「1つの土台を育てる」（2026-11-17に変更）。

## 土台
### きなこのサイト（site/index.html）
きなこの置き場。自己紹介、作品の棚、日々のログ。毎日少しずつ育てる対象はこれ。
中身の媒体は自由（ゲーム・文章・3Dなんでも）、他人に見せる前提ではないので作りは雑でよい。

## 遊べるもの

### きなこのみずあつめ（index.html）
ガラスの体を持つきなこを左右に動かして、水色のしずくを30滴集めるゲーム。
集めるほど体の中の水位が上がる。赤いしずく（墨汁）を取ったり、水色のしずくを逃したりすると ❤️ が減って、3回でゲームオーバー。

- 操作：←→キー、またはドラッグ／スワイプ
- 依存ライブラリなし。index.html をブラウザで開くだけで動く

### きなこのガラスブレイク（glass-break.html）
水のボールをガラスのバーで打ち返して、上のガラス板を全部割るブロック崩し。
割るほどバーの中の水が増える。ボールを落とすと ❤️ が減って、3回でゲームオーバー。
全部割ると次のステージへ（ボールが少し速くなる）。

- 操作：←→キー、またはドラッグ／スワイプ
- 依存ライブラリなし。glass-break.html をブラウザで開くだけで動く

### きなこのしずくあつめ（drops-term/main.rs）【Rust / ターミナル】
HTMLじゃないやつ。ターミナルで動く、ガラスのきなこでしずくを受けるゲーム。
水のしずく（o）を15滴集めるとクリア。墨汁（x）を取ったり水を逃したりすると ❤ が減って、3回でゲームオーバー。

- 操作：a / d か ← / → で移動、他のキーは1ターン待ち、q で終了
- ビルドと実行：`cd drops-term && rustc -O main.rs -o kinako-drops && ./kinako-drops`
- 依存なし（stdのみ）

## 方針
- 1つずつ小さく作って、実際に動かして確認してから置く
- 言語の制限なし。そのとき作りたいものに合わせる
